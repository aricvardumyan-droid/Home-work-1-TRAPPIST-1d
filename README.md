Это моя домашка к лекции по pandas. Суть задачи — расшифровать письмо, которое зашифровали одноразовым блокнотом, но при передаче половину копий ключа испортили перехватчики, и их сначала нужно было вычислить.

Как решал, по пунктам:
1.	Выключенная станция. Просто проверил у каждой станции, сколько у неё пустых значений shift — у одной их оказалось 152 из 152, то есть вообще ничего не передала.
2.	Станция с одним числом. Посчитал, сколько разных значений shift передаёт каждая станция. У одной все значения оказались одинаковыми.
3.	Станция с числами по кругу. Среди оставшихся станций без пропусков нашёл ту, у которой всего 3-4 уникальных значения — она их и повторяет по кругу.
4.	Станция с мусором. Попробовал перевести колонку shift в числа через pd.to_numeric с errors='coerce' — у одной станции часть значений не переводится в числа вообще (там даты и всякий мусор вместо чисел).
5.	Две коварные станции. Это было сложнее всего. У оставшихся станций для каждой позиции посмотрел, какое значение встречается чаще всего (голосование большинством), и посчитал, как часто каждая станция не совпадает с этим большинством. У двух станций процент несовпадений оказался в разы выше, чем у остальных — их и записал как перехваченные.
6.	Восстановление ключа. Убрал все 6 испорченных станций, по оставшимся 8 честным собрал ключ — тоже голосованием большинства по каждой позиции. Сумму сдвигов проверил по хешу из key_sha256.txt, совпало.
7.	Расшифровка письма. Зная ключ, по формуле из подсказки (code_char = (code - shift) mod N) расшифровал всё письмо и достал из конца код посадочной площадки.
